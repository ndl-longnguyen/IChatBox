Quick Integration Guide

To add the chatbox widget to your website, copy and paste the following HTML snippet right before the closing </body> tag.

Use the Public License Key below. Do not embed your admin login token. 
<!-- IChatBox Live Support Widget -->
<script
  src="http://localhost:8002/static/ichatbox.js"
  data-widget-key="{{ user.customer_key.key|default:'YOUR_LICENSE_KEY' }}"
  defer>
</script>

Thuộc tính tùy chọn trên thẻ script:
• data-username: Tên khách mặc định.
• data-color: Tùy biến mã màu thương hiệu (VD: data-color="#0284c7" hoặc data-color="#10b981").

JavaScript SDK Client API (Dành cho Lập trình viên)

Sau khi nhúng mã script, đối tượng window.IChatBox sẽ tự động sẵn sàng để bạn điều khiển qua JavaScript: 

// 1. Mở hoặc đóng khung chat từ bất kỳ nút nào trên trang web:
IChatBox.open();
IChatBox.close();
IChatBox.toggle();

// 2. Định danh khách hàng khi họ đã đăng nhập tài khoản trên web của bạn:
IChatBox.identify({
  name: "Nguyễn Văn A",
  email: "khachhang@gmail.com",
  phone: "0901234567"
});

// 3. Tự động gửi một tin nhắn mẫu:
IChatBox.sendMessage("Tôi cần tư vấn bảng giá");

// 4. Lắng nghe các sự kiện (Analytics, Google Tag Manager):
IChatBox.on('open', () => console.log('Khách vừa mở chatbox'));
IChatBox.on('close', () => console.log('Khách vừa đóng chatbox'));
IChatBox.on('message:received', (data) => console.log('Tin nhắn mới:', data));
