Quick Integration Guide

To add the chatbox widget to your website, copy and paste the following HTML snippet right before the closing </body> tag.

Use the Public License Key below. Do not embed your admin login token. 
<!-- IChatBox Live Support Widget -->
<script
  src="http://localhost:8002/static/ichatbox.js"
  data-widget-key="{{ user.customer_key.key|default:'YOUR_LICENSE_KEY' }}"
  defer>
</script>

Optional attributes: data-username (default guest name). Aliases supported: data-license-key, data-api-key.
